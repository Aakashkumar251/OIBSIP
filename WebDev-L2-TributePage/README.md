# To-Do Web App

An interactive to-do list application that lets users manage daily tasks, organized into pending and completed lists, with data saved across page refreshes.

## Features
- Add new tasks via input field and button
- Tasks appear instantly in the Pending list
- Mark tasks complete — moves them to the Completed list
- Edit task text inline
- Delete tasks from either list
- Live task count indicators ("X pending" / "Y completed")
- Timestamps showing when each task was added and/or completed
- Tasks persist across page refreshes using `localStorage`
- Friendly empty-state messages when a list has no items

## Tech Stack
- HTML5
- CSS3 (Grid/Flexbox layout)
- JavaScript (Vanilla) — DOM manipulation, `localStorage` persistence
