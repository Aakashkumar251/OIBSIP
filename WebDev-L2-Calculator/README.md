# Calculator

A fully functional browser-based calculator with a clean, modern UI, built using vanilla JavaScript.

## Features
- Numeric buttons (0–9) and decimal point
- Operators: addition, subtraction, multiplication, division
- Equals button to evaluate expressions
- Clear (C) button to reset
- Backspace button to remove the last entered character
- Division-by-zero handled with a friendly error message instead of crashing
- Operator chaining — supports sequential operations (e.g., 5 + 3 × 2) without a full reset
- Percent (%) function
- Full keyboard support (numbers, operators, Enter, Backspace, Escape)
- CSS Grid layout for buttons
- Responsive design for mobile screens

## Tech Stack
- HTML5
- CSS3 (Grid layout)
- JavaScript (Vanilla) — all interactions handled via `addEventListener`, no inline `onclick`
